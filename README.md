# To-Do List 🌱

A simple, interactive to-do list web application built using HTML, CSS, and JavaScript. The project features a clean, anime-inspired design with a scenic background and a sage-green color palette.

## Features
- Add new tasks using the Add button or Enter key.
- Delete tasks individually.
- Prevent empty task submissions.
- Scrollable task list.
- Responsive layout with a semi-transparent container.

## Technologies Used
- **HTML5** — Page structure
- **CSS3** — Styling, Flexbox, and visual effects
- **JavaScript** — DOM manipulation and event handling

## How to Run
1. Clone or download this repository.
2. Open  in your browser.
3. Start adding tasks!
